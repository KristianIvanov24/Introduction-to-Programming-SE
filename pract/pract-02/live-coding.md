## Live 01 - Преобразуване на `switch` в `if-else`

Пренапишете следния код от **Snippet 08**, като замените конструкцията `switch` с подходящи условни оператори `if`. Трябва да запазите поведението на оригиналната програма за всички възможни стойности на `num`.

```c++
#include <iostream>

int main() {
    int num = 2;
    
    switch (num) {
        case 1: num += 10;
        case 2: num *= 3;
        case 3: num -= 1;  
    }
    
    std::cout << num;
}
```

## Live 04 - Размяна на стойностите на две променливи

Напишете програма, която прочита две цели числа `a` и `b` и разменя стойностите им. Програмата трябва да изведе стойностите на двете променливи след размяната.

Опитайте следните два подхода:
1. размяна с помощта на трета, временна променлива;
2. размяна без използване на допълнителна променлива.

<details>
<summary>Пример 1</summary>

Вход:

```
5 10
```

Изход:

```
10 5
```

</details>

<details>
<summary>Пример 2</summary>

Вход:

```
-3 7
```

Изход:

```
7 -3
```

</details>
