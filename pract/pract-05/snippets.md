> За всеки snippet определете дали програмата се компилира. Ако се компилира, посочете какво извежда. Ако не се компилира, обяснете причината.

## Snippet 01

```c++
#include <iostream>

int main()
{
    int x = 2;
    int y = (x += 4, x *= 3, x - 2);
    std::cout << x << " " << y;
}
```

<details>
<summary>Отговор</summary>

---

Изход: `18 16`. Операторът запетая оценява последователно изразите и резултатът му е стойността на последния израз. След първите два израза `x` е `18`, а `x - 2` е `16`.

</details>

## Snippet 02

```c++
#include <iostream>

int main()
{
    int x = 5;
    int y = 3 * --x - 12 < 0 || x-- > 3;
    std::cout << x << " " << y;
}
```

<details>
<summary>Отговор</summary>

---

Изход: `3 1`. Първо `--x` променя `x` на `4`. Изразът `3 * 4 - 12 < 0` е неистина, затова се оценява и изразът `x-- > 3`. Сравнението е истина, след което `x` става `3`.

</details>

## Snippet 03

```c++
#include <iostream>
#include <cmath>

int main()
{
    double a = 0.1 + 0.2;
    double b = 0.3;
    if (a == b) std::cout << "equal";
    else if (std::abs(a - b) < 1e-9) std::cout << "close";
    else std::cout << "not equal";
}
```

<details>
<summary>Отговор</summary>

---

Изход: `close`. Поради закръглянето при операции с числа с плаваща запетая `0.1 + 0.2` обикновено не е точно равно на `0.3`, но абсолютната разлика е по-малка от `1e-9`. За по-добра четимост прагът може да се изнесе в именувана константа, например `const double EPSILON = 1e-9;`.

</details>

## Snippet 04

```c++
#include <iostream>

int main()
{
    int a = 2;
    int b = !!(a--);
    std::cout << b == 1 ? b : !b;
}
```

<details>
<summary>Отговор</summary>

---

**Не се компилира.** Операторът `<<` е с по-висок приоритет от `==` и `?:`. Изразът се групира като `(std::cout << b) == 1 ? b : !b`, а  `std::cout` не може да се сравнява с целочислената стойност `1`. Ако се добавят скоби около тернарния оператор, `std::cout << (b == 1 ? b : !b);`, програмата ще изведе `1`.

</details>

## Snippet 06

Какво ще изведе кодът при `a = 1`, `2`, `3`, `4` и `5`?

```c++
#include <iostream>

int main()
{
    int a;
    std::cin >> a;

    switch (a){
        case 1: std::cout << "X ";
        case 2:
        case 3: std::cout << "Y "; if (a == 3) break;
        case 4: { std::cout << "Z "; break; }
        default: std::cout << "W";
    }
}
```

<details>
<summary>Отговор</summary>

---

При последователни стартирания на програмата с вход `1`, `2`, `3`, `4` и `5`:

```text
a = 1 -> X Y Z 
a = 2 -> Y Z 
a = 3 -> Y 
a = 4 -> Z 
a = 5 -> W
```

Кодът се компилира. Скобите около `case 4` въвеждат блок и не променят преминаването между `case` етикетите. При липса на `break` изпълнението продължава в следващия клон.

</details>

## Snippet 07

```c++
#include <iostream>

int main()
{
    int a = 20;
    if (a - 5, a -= a += 4) a++;
    std::cout << a;
}
```

<details>
<summary>Отговор</summary>

---

Изход: `0` (в C++17 и по-нови версии). Операторът запетая първо оценява `a - 5` и изхвърля резултата. След това `a += 4` прави `a = 24`, а `a -= 24` го прави `0`. Условието на `if` е неистина и `a++` не се изпълнява.

</details>

## Snippet 08

```c++
#include <iostream>

int main()
{
    for (int i = 0; i < 10; ++i) 
    {
        for (int j = 0; j < 2; ++j) i++;
        std::cout << i << " ";
    }
}
```

<details>
<summary>Отговор</summary>

---

Изход: `2 5 8 11 `. Вътрешният цикъл увеличава `i` два пъти при всяка итерация на външния, а самият външен цикъл го увеличава още веднъж. Стойността `11` също се отпечатва, защото проверката `i < 10` е преди влизането в тялото, не преди извеждането.

</details>

## Snippet 09

Разгледайте двата цикъла **поотделно**. Ще приключи ли всеки от тях и какво извежда?

**Първа програма:**

```c++
#include <iostream>

int main()
{
    for (int i = -5; i++; i++)
        std::cout << i << " ";
}
```

**Втора програма:**

```c++
#include <iostream>

int main()
{
    for (int i = -5; ++i; i++)
        std::cout << i << " ";
}
```

<details>
<summary>Отговор</summary>

---

**Първият цикъл** започва да извежда `-4 -2 0 2 4 ...` и не завършва нормално, преди да бъде достигнато ограничение на типа `int`. При евентуално препълване на знаковия тип поведението е неопределено. **Вторият цикъл** извежда `-4 -2 ` и завършва. Разликата идва от това дали условието използва стойността *преди* (`i++`) или *след* (`++i`) увеличението. Двата цикъла трябва да се разглеждат поотделно.

</details>

## Snippet 10

```c++
#include <iostream>

int f(int a, int b = 3, int c = 2) 
{ 
    return a + b * c; 
}

int main() 
{
    int x = 4;
    std::cout << f(++x) << " " << f(x, 1);
}
```

<details>
<summary>Отговор</summary>

---

Изход: `11 7`. При първото извикване `++x` променя `x` от `4` на `5`, следователно `f(5)` връща `5 + 3 * 2 = 11`. Второто извикване `f(5, 1)` връща `5 + 1 * 2 = 7`.

</details>

## Snippet 11

```c++
#include <iostream>

int main()
{
    char a = "C";
    std::cout << a;
}
```

<details>
<summary>Отговор</summary>

---

**Не се компилира.** `"C"` е низов литерал (масив от символи), а не единичен символ от тип `char`. За присвояване на символ трябва да се използва `'C'`.

</details>

## Snippet 12

```c++
#include <iostream>

int main() 
{
    int a = 021;     
    int b = 0x12;  

    std::cout << a << " " << b;
}
```

<details>
<summary>Отговор</summary>

---

Изход: `17 18`. Литералът `021` е в осмична бройна система (`2 * 8 + 1 = 17`), а `0x12` е в шестнадесетична (`1 * 16 + 2 = 18`).

</details>
