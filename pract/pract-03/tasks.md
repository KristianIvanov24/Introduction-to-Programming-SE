## Задача 12

**Дискретно сечение на числата 🤫🙈🔢** 

Въвеждат се `n` и `k`. Нека `A` и `B` са следните множества:
- `A` = { `i` | `1 <= i <= n`, `i % k == 0` }  
- `B` = { `i` | `1 <= i <= n`, `f(i) == k` }

където `f(i) : ℕ → ℕ` връща **сумата на цифрите** на дадено естествено число `i`.
Отпечатайте `A ∩ B`.

<details>
<summary>Пример 1</summary>

Вход:
```
50 2
```

Изход:
```
Intersection(A, B) = { 2, 20 }
```

Обяснение:
```
A = { 2, 4, 6, 8, ..., 46, 48, 50 } (кратни на 2)
B = { 2, 11, 20 } (числа <= 50 със сума на цифрите == 2)
A ∩ B = { 2, 20 }
```

</details>

<details>
<summary>Пример 2</summary>

Вход:
```
30 6
```

Изход:
```
Intersection(A, B) = { 6, 24 }
```

</details>

<details>
<summary>Пример 3</summary>

Вход:
```
200 12
```

Изход:
```
Intersection(A, B) = { 48, 84, 156, 192 }
```

</details>
