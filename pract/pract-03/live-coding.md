## Live 01 - Палиндром?

Напишете програма, която прочита цяло число `n` от стандартния си вход и проверява дали `n` е палиндром.

Палиндром наричаме число, чиито цифри се четат еднакво отляво надясно и отдясно наляво.

<details>
<summary>Пример 1</summary>

Вход:
```
39293
```

Изход:
```
39293 is a palindrome!
```

</details>

<details>
<summary>Пример 2</summary>

Вход:
```
807
```

Изход:
```
807 isn't a palindrome!
```

</details>

<details>
<summary>Пример 3</summary>

Вход:
```
1
```

Изход:
```
1 is a palindrome!
```

</details>

## Live 02 - Прости числа

Напишете програма, която прочита неотрицателно цяло число `n` от стандартния вход и извежда всички прости числа в затворения интервал `[0, n]`.

Просто число наричаме естествено число, по-голямо от 1, което има точно два положителни делителя - 1 и самото себе си.

<details>
<summary>Пример 1</summary>

Вход:
```
20
```

Изход:
```
Primes from 0 to 20: 2, 3, 5, 7, 11, 13, 17, 19
```

</details>

<details>
<summary>Пример 2</summary>

Вход:
```
10
```

Изход:
```
Primes from 0 to 10: 2, 3, 5, 7
```

</details>

<details>
<summary>Пример 3</summary>

Вход:
```
1
```

Изход:
```
Primes from 0 to 1:
```

</details>
